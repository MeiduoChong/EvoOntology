欢迎使用 EvoOntology 语义层浏览器

一张交互式地图，帮你看懂当前语义层版本

这个页面是什么？

本页面由 EvoOntology 语义层自动渲染（只读快照，不修改任何语义层状态）。它把当前本体版本可视化为一张图谱：业务概念（Term）如何落地到数据库表列（Mapping）、受哪些使用约束（Constraint）、由哪些证据（Evidence）支撑，以及概念之间的语义关系（Relation）。

三个视图

  • 本体内容— 交互式语义图谱，支持搜索、过滤、展开 / 收起
  • Schema 层— 对象类型、受控关系取值与结构引用规则
  • Tool 层— 智能体查询语义层时使用的 MCP 工具

快速上手

  • 点击图中的节点或连线，在右侧面板查看详情
  • 双击 Term 卡片，展开或收起它的 Mapping / Constraint / Evidence
  • 顶栏可搜索任意对象；左上角图例查看统计，左下角过滤器控制显示内容
  • 右上角可在中文与 English 之间切换
